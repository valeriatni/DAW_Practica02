# Registro de Tareas con JavaScript

## Descripción
Este proyecto consiste en una aplicación web simple que permite al usuario registrar tareas y visualizarlas dinámicamente. Se hace uso de JavaScript para la manipulación del DOM mediante eventos.

---

## Objetivo
Aplicar conceptos básicos de JavaScript como:
- Eventos (click)
- Manipulación del DOM
- Uso de arreglos
- Conversión a formato JSON

---

## Funcionamiento

1. El usuario ingresa una tarea en el campo de texto.
2. Al presionar el botón **"Agregar tarea"**, la información se guarda en un arreglo.
3. Al presionar el botón **"Mostrar tareas"**, se muestran todas las tareas almacenadas en el DOM.

---

## Tecnologías utilizadas

- HTML
- JavaScript

---

## Conceptos aplicados

- `getElementById`
- `addEventListener`
- `textContent`
- `JSON.stringify`

---

## Ejecución

1. Descargar o clonar el repositorio
